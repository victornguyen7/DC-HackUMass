Forecast ledger

Every adopted plan writes its forecast to an append-only table in Tiger Data before the night. The database stamps the time and refuses edits and deletes. Each forecast is scored once that night's numbers arrive.

What this shows, and what it doesn't

  • It shows the calibrated ranges contain later nights about as often as they claim, and that seed-only ranges are far too narrow.
  • It doesn't show the engine matches Worcester. The recorded history is generated by the same engine plus noise, so this checks the method, not the kitchen.
  • The tables are shaped like MetaFoodX, LeanPath and swipe exports. Real exports load and calibrate with no code change.
