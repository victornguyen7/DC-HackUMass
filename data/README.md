# data/

```
raw/                         original uploads, never edited
  menu/worcester_menus_2026-11-13_to_2026-11-20.json   umassdining.com snapshot (read by `dcsim prepare`)
  research/*.json            attendance, population, waste, tools-ecosystem reports, assumption audit
  layout/worcester_second_floor_plan.png               published design drawing with location key

sources/                     raw/research split by topic (python3 data/synthetic/worcester/         SYNTHETIC "recorded" history (dcsim waste-gen): consumption.csv (MetaFoodX shape),
                             waste_log.csv (LeanPath shape), nights.csv, backtest.json; _ground_truth.json is hidden

scripts/split_sources.py)
  registry.json              every citation by source_id (60), with the files that cite it; same_as links duplicate ids
  attendance/                Worcester meal volume (≈12,000 meals/day, 2023) + the data request to send Dining
  population/                enrollment, diet patterns, allergies, cuisine preferences, athletics,
                             religious diets, choice drivers, candidate model features + gaps
  calendar/                  dated November 2026 events + audited target-date flags
  waste/                     FY2017–FY2026 timeline, oz-per-swipe series, comparisons, vendor claims, limits
  ecosystem/                 one file per tool (Metafoodx, FoodPro, meal swipes, FRN, anaerobic) + data flow
  audit/                     assumption audit: assumptions/A01…A17 (each with its facts + data requests),
                             verified_facts, corrections, data_requests (R01–R08), method

menu/<date>/<meal>.json      raw menu split per date and meal (breakfast, lunch, dinner, late_night);
menu/index.json              source_attributes and icons dropped (still in raw/)

worcester/                   ENGINE INPUTS (read by dcsim)
  ASSUMPTIONS.md             what is sourced, what is still a guess
  dc.json stations.json personas.json kitchen_defaults.json overrides.json
  crowd_by_date.json         crowd multipliers by weekday and date event (placeholders, ISSUES E5)
  calibration_targets.json   the team's observations as tests (engine/tests/test_calibration_targets.py)
                             kitchen_defaults.json also holds planner_by_period (late-night taper) and
                             resources (cooks and equipment, placeholders); overrides.json holds
                             station_by_date (Nov 18 carving line)
  layout/floor_plan.json     station + key-point positions in meters, measured off the floor plan
  calendar.json              weekday + events per simulated date (context; the engine reads crowd_by_date.json)
  menus/ kitchen/            generated by `dcsim prepare`

scripts/split_sources.py     regenerates sources/, menu/ and worcester/calendar.json from raw/
```

Rules carried over from the research files: `null` means not established (not zero); keep dates and denominators attached to values; meals ≠ distinct students; vendor claims stay vendor claims.
